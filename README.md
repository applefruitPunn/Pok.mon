# Egalcraft

GitHub Pages launcher for the Egalcraft browser-game project.

## Game files

Place the game you are authorized to distribute in `game/`, with an `index.html` entry point. The homepage links to that folder.

## GitHub Pages

The included GitHub Actions workflow deploys the repository to GitHub Pages whenever `main` is updated.
